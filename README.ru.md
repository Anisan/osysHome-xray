# xray - Модуль диагностики системы

![xray Icon](static/xray.png)

Инструмент диагностики и мониторинга системы для просмотра информации о системе, статистики базы данных, статуса кэша и уведомлений.

## Описание

Модуль `xray` предоставляет комплексные возможности диагностики и мониторинга системы для платформы osysHome. Он позволяет просматривать информацию о системе, статистику пула базы данных, управление кэшем, статус хранилища объектов и управление уведомлениями.

## Основные возможности

- ✅ **Информация о системе**: Просмотр деталей системы, версии Python, информации о платформе
- ✅ **Мониторинг пула базы данных**: Мониторинг статистики пула подключений базы данных
- ✅ **Управление кэшем**: Просмотр и очистка кэша
- ✅ **Хранилище объектов**: Просмотр объектов в хранилище памяти
- ✅ **Управление уведомлениями**: Управление системными уведомлениями
- ✅ **Информация о модулях**: Просмотр установленных модулей и версий
- ✅ **Поддержка виджетов**: Виджет панели управления

## Панель администратора

Модуль предоставляет комплексный административный интерфейс с несколькими вкладками:

### Вкладка System
- Версия Python
- Информация о платформе
- Установленные пакеты
- Ресурсы системы

### Вкладка Database
- Статистика пула подключений
- История пула
- Активные подключения
- Информация о размере пула

### Вкладка Cache
- Статистика кэша
- Функциональность очистки кэша
- Информация о размере кэша

### Вкладка Objects
- Объекты в хранилище памяти
- Функциональность очистки хранилища
- Количество объектов

### Вкладка Notifications
- Просмотр уведомлений
- Отметка как прочитано/непрочитано
- Удаление уведомлений
- Очистка всех уведомлений

### Вкладка Modules
- Список установленных модулей
- Версии модулей
- Информация о модулях

## API

Модуль предоставляет RESTful API endpoints:
- **GET /api/xray/...**: API диагностики системы

## Использование

### Просмотр информации о системе

1. Перейдите в модуль xray
2. Выберите нужную вкладку
3. Просмотрите информацию о системе
4. Выполните операции обслуживания

## Технические детали

- **Мониторинг пула**: Мониторинг пула базы данных в реальном времени
- **Кэш**: Интеграция Flask-Caching
- **Хранилище**: Интеграция ObjectsStorage
- **Уведомления**: Управление системными уведомлениями
